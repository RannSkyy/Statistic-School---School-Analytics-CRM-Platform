# 📊 Statistic School

A modern School Analytics & Admissions CRM platform built with React, TypeScript, and Tailwind CSS to help educational institutions manage enrollment pipelines, monitor performance metrics, and gain actionable insights through an interactive analytics dashboard.

---

## ✨ Features

- 📈 Interactive analytics dashboard with real-time statistics
- 🏫 School profile with accreditation and campus switcher
- 👥 Admissions CRM for managing leads and school visits
- 🔍 Real-time search and pipeline status filtering
- ➕ Quick lead creation with detailed management modal
- 📄 CSV export for admissions pipeline data
- 🎯 Interactive target tracking and progress simulation
- 💰 Regional revenue intelligence with detailed analytics
- 🧮 District ROI simulator for enrollment projections
- 🏛 SIS integration showcase and compliance overview
- 💳 Responsive pricing plans with monthly/yearly billing
- ⭐ Testimonials and institutional case studies
- ❓ Searchable interactive FAQ section
- 📬 Consultation and demo request form with validation
- ⬆️ Scroll progress indicator with back-to-top button
- 📱 Fully responsive across mobile, tablet, and desktop

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/statistic-school.git
```

### Navigate into the project

```bash
cd statistic-school
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
